# OpenBudget Research

This folder contains ongoing deep research for OpenBudget's product and technical direction.

## Files

- `research-log.md` - Running notes with source-backed findings, updated incrementally.
- `architecture-and-capabilities.md` - Current-state analysis of architecture and implemented capabilities.
- `roadmap-and-opportunities.md` - Forward-looking roadmap, opportunity map, and phased execution proposals.
- `implementation-backlog.md` - Prioritized execution backlog with epics, schema/API slices, and acceptance criteria.

## Update Policy

Research notes are written incrementally during investigation to preserve progress.
