# Add a wallet from any major chain

Adding a crypto wallet is now one step: paste an address or an extended public key and OpenBudget works out the chain, from Bitcoin and Ethereum to Solana, Tron and the XRP Ledger. For an Ethereum-style address it checks which networks hold something and picks them for you, so you can add or drop a chain with a tap. While your wallet is read for the first time you see which chains are being read, and a successful add lands with an ADDED stamp. If you paste a private key or a recovery phrase, OpenBudget empties the field straight away, tells you never to share it, and sends nothing anywhere.
