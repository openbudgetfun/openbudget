# One tax profile form for every country

The tax profile screen now renders the questions the entity's rule pack declares (`profileQuestions`) and no longer branches on a country: there is no `is GbTaxProfile`-style check left in the app, so a new country's pack gets its form without editing the screen. Labels, help text and choice options come from ARB through `taxQuestionLabel`, a resolver generated by `dart run tool/generate_tax_question_labels.dart` into `tax_question_labels.g.dart`; the tool fails when a pack names a key the ARB file lacks, `--check` runs in CI's lint job, and a contract test finds every declared key. The form keeps today's fields, grouping, save behaviour and stored JSON, shows a count or amount that does not parse as an inline error under its field with one shared message, and reads wide windows in a readable column. The old per-country strings the screen used are removed from `app_en.arb`. Widget tests fill every question of each pack and assert the saved profile JSON byte for byte, and a test fails if code under `lib/` checks for a country's profile class.
